# Build & Flash

Проект использует ESP-IDF v5.2.

## Сборка

```bash
bash scripts/build.sh
```

После первой сборки для быстрой инкрементальной сборки:

```bash
ninja -C build
```

## Прошивка

```bash
bash scripts/flash.sh /dev/ttyUSB0
```

## Полезные команды

- `idf.py menuconfig` — конфигурация проекта
- `idf.py monitor` — монитор UART
- `ninja -C build` — быстрая пересборка (без вызова idf.py)

## Зависимости

ESP-IDF устанавливается через `bash scripts/setup.sh`.

# Тесты

Перед сборкой прошивки (`idf.py build`) нужно всегда запускать тесты:

```bash
cmake --build build_test --target check
```

Или пересобрать и запустить:

```bash
cmake -B build_test -S test && cmake --build build_test && ./build_test/run_tests
```

# Общение

Указывай на грамматические, лексические и пунктуационные ошибки в моих промтах
на русском или английском языке. Я хочу быть грамотнее.

# Правила работы с котлом

Если ты управляешь котлом напрямую (через API) — всегда возвращай состояние
котла в то, в котором оно было до эксперимента. Например: если отопление было
выключено, а ты его включил для проверки — выключи обратно после завершения.

# Тесты

Тесты нельзя исправлять без веской причины. Если тест падает — сначала нужно
разобраться и рассказать, в чём ошибка в самом тесте (не в production-коде), и
только потом с согласия пользователя править тест.
