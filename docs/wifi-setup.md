## Синий светодиод: что означает мигание

Синий светодиод на плате (GPIO 2 на типичных ESP32 devkit) — индикатор состояния сети. **Мигание после включения — это нормально**: оно означает, что WiFi-соединение ещё не установлено:

| Поведение светодиода | Значение |
|---|---|
| Частое мигание | Активна точка доступа настройки `Baxi-OT-Setup-XXXXXX`, устройство ждёт конфигурации |
| Редкое мигание | Идёт подключение к сохранённой WiFi-сети |
| Погашен / горит постоянно `TODO(verify)` | Подключено — штатная работа |

Если светодиод **мигает минутами** после старта — устройство не может добраться до вашей сети: роутер выключен или вне зоны, сменился пароль, либо учётные данные были стёрты. См. ## Первый запуск: портал настройки

На свежей прошивке (или после сброса настроек) у устройства нет данных WiFi, поэтому оно поднимает **собственную точку доступа**:

- **SSID:** `Baxi-OT-Setup-XXXXXX` (суффикс образован от MAC-адреса чипа, поэтому уникален для каждого устройства)
- **Адрес портала:** `http://192.168.4.1` — большинство телефонов открывают captive-portal автоматически сразу после подключения

В портале доступны два режима:

### Режим 1 — подключение к домашней сети (рекомендуется)

1. Выберите сеть из списка сканирования (или введите SSID вручную).
2. Введите пароль и сохраните.
3. Устройство перезагрузится, подключится к роутеру, а точка доступа настройки исчезнет.
4. Найдите IP устройства в списке DHCP-клиентов роутера и откройте `http://<ip-устройства>`.

Совет: закрепите за устройством статический DHCP-адрес в роутере — адрес дашборда и поведение MQTT станут заметно предсказуемее.

### Режим 2 — автономная точка доступа

Без роутера и интернета — шлюз постоянно держит собственную точку доступа и отдаёт дашборд на `http://192.168.4.1`. Работает всё, кроме функций, которым нужен интернет (синхронизация времени по NTP; суточное расписание тогда зависит от отсутствия времени — статус синхронизации смотрите на вкладке «Инфо») и внешнего MQTT-брокера.

## Смена WiFi позже

Откройте дашборд → вкладка **WiFi**. Можно пересканировать эфир, сменить сеть или переключиться между режимами клиента и точки доступа. Состояние подключения и RSSI показываются вживую.

## Поведение при переподключении

Прошивка никогда не сдаётся:

- Если роутер пропал (отключение света, перезагрузка) — устройство пробует переподключиться вечно, с экспоненциальным backoff.
- Если данные стали неверными или сети давно нет, устройство снова поднимает точку доступа настройки, чтобы можно было перенастроить без перепрошивки. `TODO(verify): точный таймаут отката.`
- MQTT переподключается автоматически после возвращения WiFi; discovery для Home Assistant публикуется заново при каждом реконнекте.

## Сброс к заводским настройкам

- **Из дашборда:** вкладка WiFi → **«Сбросить все настройки сети»** (красная кнопка внизу). Рядом с блоком состояния есть и **«Переключиться на точку доступа»** — переводит устройство в автономный режим точки доступа, ничего не стирая.
- **С компьютера:** полная очистка NVS — стирает WiFi, настройки MQTT, калибровку счётчика газа и расписание:

  ```bash
  idf.py -p /dev/ttyUSB0 erase-flash
  bash scripts/build_and_flash.sh /dev/ttyUSB0
  ```

## Диагностика

| Симптом | Что проверить |
|---|---|
| Синий светодиод продолжает мигать после старта | Устройство всё ещё без WiFi: либо точка доступа настройки ждёт вас (частое мигание), либо не удаётся достучаться до сохранённой сети (редкое мигание): роутер выключен, вне зоны, сменился пароль |
| Нет сети `Baxi-OT-Setup-…` после прошивки | Подождите ~30 с после загрузки; посмотрите серийный монитор (`idf.py monitor`) на ошибки старта; убедитесь, что прошивка залилась без ошибок |
| Captive-portal не открывается сам | Откройте `http://192.168.4.1` вручную; отключите мобильный интернет на телефоне, чтобы трафик не уходил в обход точки доступа |
| Устройство в сети, но вы его не находите | Ищите hostname в списке DHCP роутера; либо смотрите серийный лог — IP печатается при подключении |
| Дашборд тормозит / отваливается | Проверьте RSSI на вкладке WiFi; антенны ESP32 не любят металлические кожухи котлов — вынесите плату или возьмите плату с внешней антенной |
| Устройство периодически выпадает из WiFi | Закрепите DHCP-адрес; посмотрите логи роутера; учтите, что прошивка отключает энергосбережение WiFi ради стабильности — если меняли это в menuconfig, верните обратно |
| Введён неверный пароль при настройке | Дождитесь повторного появления точки доступа настройки или сделайте сброс |

## Замечания о безопасности

- Дашборд и REST API отдаются по обычному HTTP в локальной сети и не имеют аутентификации — **не** пробрасывайте устройство в интернет. Для удалённого доступа используйте VPN в домашнюю сеть (WireGuard, Tailscale и т.п.).
