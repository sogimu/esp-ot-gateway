## ADDED Requirements

### Requirement: Цикловая блокировка по решению CH

Цикловая блокировка SHALL взводиться переходом `pid_ch_enabled` из `true` в `false` (решение PI), а не погасанием пламени. Значение `pid_cycle_lockout = 0` SHALL отключать блокировку.

#### Scenario: PI выключил CH
- **WHEN** PI переводит `pid_ch_enabled` из `true` в `false`
- **THEN** на `pid_lockout_sec` секунд CH остаётся выключенным, уставка равна `pid_sp_min`

#### Scenario: Котёл тактует сам
- **WHEN** пламя гаснет и зажигается при включённом CH (штатная модуляция)
- **THEN** цикловая блокировка не взводится

#### Scenario: Блокировка отключена
- **WHEN** `pid_cycle_lockout = 0`
- **THEN** выключение CH не блокирует повторное включение

### Requirement: Фактический интервал интегрирования

Интеграл SHALL накапливаться по фактическому времени между расчётами (clamp 1–300 с), а не по значению `pid_dt_sec`.

#### Scenario: Задержка опроса
- **WHEN** расчёт произошёл позже планового интервала
- **THEN** интеграл учитывает фактическое прошедшее время

### Requirement: Bumpless-старт и асимметричное рассасывание

При включении PID интеграл SHALL стартовать с последней рабочей уставки (если она известна), иначе с `pid_sp_min`. При комнате выше цели интегральный коэффициент SHALL временно увеличиваться (×3) для более быстрого снижения уставки.

#### Scenario: Возврат из ручного режима
- **WHEN** PID включается после ручного режима
- **THEN** интеграл стартует с последней рабочей уставки, а не с минимума

#### Scenario: Комната выше цели
- **WHEN** комната выше цели
- **THEN** интеграл уменьшается втрое быстрее, чем растёт при симметричной ошибке
