## Context

Сейчас база обучается (перенос интеграла + слив) и зависит от фактического тактования котла. Короткие транзиенты (дверь/окно) сдвигают базу вверх, и она не возвращается. Уличная температура уже приходит от котла (ID 27) и доступна через `ITemperatureSource::outside()` (с коррекцией offset).

## Goals / Non-Goals

**Goals:**
- База по погодной кривой: `−20 °C → 30 °C`, `+15 °C → 25 °C`, кламп в `[sp_min, sp_max]`.
- Fallback 26 °C при недостоверной улице.
- Настройка `wc_sp_cold` / `wc_sp_warm` (NVS, API, веб).
- Удаление обучения базы (`BASE_TAU`, слив, перенос, `base_inited_`, `last_auto_output_`).

**Non-Goals:**
- Не меняем комнатный гистерезис, перегрев, цикловую блокировку, ГВС.
- Не трогаем `pid_sp_min/max` (остаются жёсткими границами).

## Decisions

- Точки кривой: `WC_OUT_COLD = −20`, `WC_OUT_WARM = +15` — константы; настраиваются только `wc_sp_cold` / `wc_sp_warm`.
- `base = wc_sp_cold + (wc_sp_warm − wc_sp_cold) · (Tout − WC_OUT_COLD)/(WC_OUT_WARM − WC_OUT_COLD)`, затем `clamp(sp_lo, sp_hi)`.
- Валидность улицы: `isfinite(tout) && tout > −60 && tout < 60`. Иначе `base = 26`.
- `trim` остаётся ограниченным `±TRIM_MAX` и дополнительно `[sp_lo − base, sp_hi − base]`; anti-windup в `pid_step` по этим границам.
- `UNWIND_GAIN = 3` (быстрое рассасывание при комнате выше цели) оставляем.

## Risks / Trade-offs

- [Кривая может не подойти дому] → настраивается двумя ползунками.
- [Улица недостоверна / датчика нет] → fallback 26 °C, пишем в журнал.
- [Уличная температура может быть шумной] → при необходимости добавить медленный фильтр (не в этой итерации).
