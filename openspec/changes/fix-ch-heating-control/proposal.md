## Why

Ручной режим отопления работает некорректно по трём независимым причинам: уставки обрезаются по захардкоженным диапазонам, которые не совпадают с реальными границами котла и дублируются в нескольких слоях; обещанный в UI «Гистерезис CH» не реализован в коде (котёл и насос не выключаются по комнате/подаче); при рукопожатии шлюз пишет в Master Configuration (ID 2) эхо Slave Configuration (ID 3), что семантически неверно. Всё это мешает добиться «штатного» поведения котла: удержание уставки и остановка насоса между циклами нагрева.

## What Changes

- **Единый источник истины для границ уставок**: диапазоны CH/DHW берутся из ID 49/48, которые сообщает котёл, и обрезают значения во всех точках входа (HTTP, MQTT, расписание, use case), не шире, чем поддерживает котёл.
- **CH-гистерезис**: в ручном режиме добавлен on/off-контур по температуре подачи (гистерезис), который снимает/поднимает `CH_ENABLE`, позволяя котлу гасить горелку и останавливать насос (с выбегом) между циклами.
- **Исправление Master Config**: при рукопожатии в ID 2 записывается собственная конфигурация мастера (флаги + Member ID), а не эхо ID 3.

## Capabilities

### New Capabilities

- `ch-heating-control`: корректное управление отоплением CH — границы уставок как единый источник истины, гистерезис включения/выключения отопления, корректная запись Master Configuration при рукопожатии.

## Impact

- `main/application/use_cases/system_config_interactor.cpp` — обрезка уставок по границам котла.
- `main/infrastructure/driving/http_controller_adapter.cpp` — обрезка в обработчике `POST /api/control` и `POST /api/schedule`.
- `main/infrastructure/driving/mqtt_interactor.cpp` — обрезка уставок из MQTT (если применимо).
- `main/application/use_cases/boiler_poll_interactor.cpp` — чтение ID 49/48, гистерезис CH, исправление ID 2.
- `main/application/services/` — новый сервис CH-гистерезиса (по образцу `DHWHysteresisService`).
- `main/application/ports/driven/iheating_state_store.h` + адаптер — поле гистерезиса CH (если не конфигурируется как константа).
- `main/infrastructure/driving/web_page.h` — привязка UI к границам и гистерезису (слайдер уже частично использует `ch_sp_min/max`).
- `docs/api.md` — актуализация полей и диапазонов.
