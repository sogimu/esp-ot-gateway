## Why

При переключении режима СО с «Адаптивный» на «Ручной» и обратно цель комнаты сбрасывается в 0 °C. Настроенная уставка теряется, PID работает с целью 0 °C, и пользователю приходится каждый раз вводить её заново.

## What Changes

- Сохранять `pid_target_room` при выключении PID по смене режима СО (`PidPollInteractor::disable()`) и в выключенной ветке `PidPollInteractor::execute()`.
- Сохранять последнюю измеренную комнатную температуру в тех же путях (цель — настройка, комнатная температура — последнее измерение).
- Добавить регрессионные тесты на цикл смены режима и на выключенный poll.

## Capabilities

### New Capabilities
- `pid-room-control`: PID-регулирование комнатной температуры для СО — цель комнаты, переключение ручного/адаптивного режима и отображение цели/комнаты в интерфейсе.
